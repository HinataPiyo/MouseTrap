# MouseTrap

学校の部屋を探索し、人物や物品との会話・イベントを通じて進行する2D探索ゲームです。Unityで開発中です。

## ゲーム概要

プレイヤーは部屋を歩き回り、調べられるオブジェクトを見つけてイベントを進めます。現時点の実装には、職員室と図書室、会話、アイテム取得、キャラクター切り替え、部屋移動があります。作品全体の物語や最終的なクリア条件は、まだこのリポジトリから確定できません。

## 操作

| キー | 操作 |
| --- | --- |
| W / A / S / D | 移動 |
| E | 近くの対象を調べる。対象によってはもう一度押して操作状態を解除 |
| Space | 会話を進める。文字表示中は全文を表示 |
| Tab | インベントリを開閉 |
| Q | キャラクター情報を開閉 |
| 1～5 | キャラクター切り替え（解放済みキャラクターのみ） |
| Escape | インベントリ／キャラクター情報／部屋移動画面を閉じる |

## 開発環境

- Unity 6 (6000.0.51f1)
- 主なパッケージ: Input System、Universal Render Pipeline、UI Toolkit、uGUI

Unity Hubで上記バージョンのUnityを選び、このフォルダーをプロジェクトとして開いてください。現在のBuild Settingsには `StaffroomScene` と `LibraryScene` が登録されています。
